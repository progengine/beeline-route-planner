# Билайн Бизнес — интеллектуальный сервис планирования маршрутов

Прототип помощника диспетчера: распределяет заявки между выездными
инженерами, строит маршруты с учётом временных окон/квалификации/транспорта,
показывает план на карте и умеет перестраивать его при изменениях.

## Структура проекта

```
bilayn-route-planner/
├── backend/
│   ├── app/
│   │   ├── models.py     # доменные модели: Заявка, Инженер, Событие, PlanResult
│   │   └── config.py     # константы (скорости, лимиты, допущения)
│   └── requirements.txt
├── data/                 # тестовые наборы данных (CSV/JSON)
├── frontend/             # интерфейс (Streamlit/Folium или React/Leaflet)
└── README.md
```
